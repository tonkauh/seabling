# SEABLING Cultural Atlas

A full-screen, interactive Southeast Asia map prototype built with Next.js,
TypeScript, SVG, and Tailwind CSS. Explore all 11 ASEAN country zones, view
cultural highlights and workshops, and save workshop registrations from the
country drawer.

Drag to pan, use the mouse wheel or pinch to zoom, or use the on-screen zoom
controls. The map is drawn locally as SVG and does not require an external map
service or access token.

## Run locally

```bash
npm install
npm run dev
```
